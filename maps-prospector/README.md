# Maps Prospector

Go-приложение для поиска бизнесов в Яндекс Картах, проверки ссылки на сайт и автоматического создания очереди обращений.

## Что реализовано

- Браузерный сбор публичных карточек Яндекс Карт без API-ключа; дополнительный адаптер API поиска организаций.
- Статусы `listed`, `not_listed`, `unknown`. «Сайт не указан» не означает «сайта не существует». При изменении разметки или неполной загрузке используется `unknown`, такой бизнес в очередь не попадает.
- Сохранение результатов, дедупликация по ID бизнеса, просмотр ссылок и экспорт черновиков.
- Поиск по расписанию; CSV городов с населением **строго меньше 500 000** и 20 стартовых категорий. Категории можно менять.
- Контакты берутся из опубликованных ссылок Telegram/WhatsApp и телефонного номера. Проверки WhatsApp и Telegram выполняются перед отправкой; Telegram-каналы и группы не используются как адрес личного обращения. VK-сообщество определяется по опубликованной ссылке через `utils.resolveScreenName`; программа не угадывает получателя по названию бизнеса.
- Личный Telegram через MTProto (`gotd/td`), обычный WhatsApp как привязанное устройство (`whatsmeow`), личный профиль VK через `messages.send`.
- Очередь с дневным лимитом, паузой и журналом результатов. Один бизнес и один контакт получают максимум одно обращение. После неопределённого результата и прерывания процесса повтор отключён; требуется проверить историю сообщений.

Это первая версия, а не подтверждённый запуск на живых аккаунтах. Разбор Яндекса проверен на контролируемых HTML-образцах. Доступ к реальному Яндексу в текущей облачной среде блокируется прокси; актуальные селекторы и полный сценарий нужно проверить после предоставления доступа. Аккаунты не подключены, настоящие сообщения не отправлялись. Факт принятия сообщения API не равен доставке или прочтению.

## Запуск

Нужны Go **1.26+** и Chromium/Chrome с рабочей песочницей. Зависимости зафиксированы в `go.mod` и `go.sum`.

```sh
go mod download
go build -buildvcs=false -p 2 -o maps-prospector .
./maps-prospector --chromium /usr/bin/chromium
```

В текущей среде Go установлен в `/workspace/toolchains/go/bin`. Для сборки используются доступные для записи кеши:

```sh
GOCACHE=/workspace/.cache/go-build GOPATH=/workspace/.cache/gopath /workspace/toolchains/go/bin/go build -buildvcs=false -p 2 -o maps-prospector .
```

HTTP-интерфейс слушает `127.0.0.1:8080`. Поиск запускается формой «категория и город». Автоотправка **выключена**, пока не задан `--send`. HTTP-интерфейс не имеет авторизации: оставляйте его на loopback; для внешнего доступа требуется защищённый reverse proxy. Программу с личными аккаунтами рекомендуется запускать на своём компьютере: облачный HTTPS-прокси может не поддерживать прямые MTProto-соединения.

Профиль браузера, результаты, очередь и сессии находятся в `data/`. Сессии дают доступ к аккаунтам: не публикуйте эту папку, не прикладывайте её к архивам и не сохраняйте в Git. Не запускайте одновременно две копии приложения с одной папкой `data/`: хранилище защищает горутины одного процесса, межпроцессная блокировка пока не реализована.

В этой облачной машине системный Chromium имеет несовместимую конфигурацию sandbox. Приложение не отключает её автоматически. Тесты Chromium используют локальные доверенные HTML-образцы и отключают sandbox только для этого теста. Для живого сбора нужен Chromium с корректно настроенной sandbox на рабочей машине либо поддерживаемый изолированный браузерный runtime.

## Подключение аккаунтов

Никогда не передавайте пароли, коды входа, QR или сессии в чат.

### Telegram: личный аккаунт

Создайте приложение на `my.telegram.org` и задайте `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` в защищённом окружении процесса. Затем выполните **локально в интерактивном терминале**:

```sh
./maps-prospector --login telegram
```

Телефон, код и 2FA запрашиваются со скрытым вводом. Регистрация новых Telegram-аккаунтов не выполняется. Для обращения нужен опубликованный username личного контакта. Публичный канал бренда сам по себе не даёт адрес для личного сообщения.

### WhatsApp: обычный аккаунт

```sh
./maps-prospector --login whatsapp
```

В своём WhatsApp откройте «Связанные устройства» → «Привязка устройства» и отсканируйте QR из **своего локального терминала**. Используется сторонняя библиотека WhatsApp Web, а не официальный WhatsApp Business API; совместимость зависит от изменений протокола. Перед отправкой проверяется регистрация опубликованного номера в WhatsApp.

### VK: личный профиль без приложения и API-токена

Для обычного личного профиля предусмотрен экспериментальный браузерный режим. Установите Chrome и выполните локально:

```sh
./maps-prospector --login vk
```

В открывшемся Chrome войдите в VK обычным способом, откройте раздел сообщений, вернитесь в консоль и нажмите Enter. Пароль и коды вводятся только на сайте VK. Используется отдельный профиль `data/accounts/vk-browser`; программа не извлекает cookie или токены. Не отправляйте этот профиль в чат или архив.

`--vk-backend browser` используется по умолчанию. Браузерная отправка разрешается только после нахождения опубликованной кнопки сообщения с отрицательным ID сообщества, проверки адреса открытого диалога и совпадения его `data-peer`. Имеющийся черновик не перезаписывается. Текст и адресат проверяются перед нажатием отправки, результат подтверждается новым исходящим номером сообщения. Если после нажатия подтверждения нет, повтор отключается и вся браузерная отправка VK приостанавливается. Проверьте историю и снова выполните локальный вход для снятия паузы.

**Браузерный режим пока проверен только на контролируемых образцах DOM**, а не на действующем интерфейсе вашего VK. Он поддерживает конкретные признаки разметки и может отказаться отправлять при другой версии интерфейса. Он не обходит CAPTCHA и не гарантирует сообщение закрытым сообществам. До рабочей кампании обязательна проверка на собственном тестовом сообществе владельца аккаунта: запустите `test-vk.cmd` или `./maps-prospector --test-vk-group https://vk.com/ваше_тестовое_сообщество`. Команда отправляет одно сообщение «Тест подключения Maps Prospector. Проверка собственного сообщества.» и не запускает рабочую кампанию. Вводите адрес только своего тестового сообщества. Профиль браузера и авторизация не подключены в облаке.

Дополнительный API-режим доступен при наличии пользовательского `VK_ACCESS_TOKEN` приложения с разрешением `messages`:

```sh
./maps-prospector --check-vk
./maps-prospector --vk-backend api --send
```

Самого личного аккаунта недостаточно для API-доступа. Проверяются пользователь через `users.get` и разрешение через `account.getAppPermissions`; короткое имя сообщества разрешается через `utils.resolveScreenName`. Закрытые сообщения, отсутствие прав и CAPTCHA приводят к отказу. Используйте официальный способ авторизации своего приложения. Токены, пароли и коды не передавайте в чат.

Официальная схема API VK: https://github.com/VKCOM/vk-api-schema/blob/master/messages/methods.json .

## Автоматический режим

Одна поисковая задача:

```sh
./maps-prospector --query 'автосервисы в городе Псков' --scan-interval 1h
```

После локального подключения аккаунтов:

```sh
./maps-prospector --query 'автосервисы в городе Псков' --scan-interval 1h --send --daily-limit 10 --send-interval 5m
```

Если контактов нет, сообщение не создаётся. Шаблон:

> Здравствуйте! Я веб-разработчик, занимаюсь созданием сайтов. Могу бесплатно сделать для вас демонстрационный вариант сайта. Посмотрите: если понравится, обсудим дальнейшую работу.

Скрипт не создаёт сайты: слово «бесплатно» в шаблоне описывает ваше предложение демоверсии. Перед запуском убедитесь, что предложение соответствует вашей работе.

Поиск по городам:

```sh
./maps-prospector --cities cities.csv --scan-interval 1h --send --daily-limit 10
```

CSV должен иметь заголовок `city,population,population_year,source`. Численность — целое число; год — от 2020 до текущего; источник — непустой. Города с численностью >=500000 исключаются. Программа проверяет формат и порог, но не достоверность введённых данных. Для получения списка кандидатов из Wikidata выполните `./maps-prospector --refresh-cities cities.csv`. Берутся последние опубликованные данные не старше 2020 года, но Wikidata не гарантирует полноту списка или актуальность населения: проверяйте дату и источник перед рабочей кампанией. Живая загрузка в облаке пока заблокирована прокси; тестовые числа из тестов не используются в рабочих кампаниях.

Все пары «город × категория» обходятся циклически, одна поисковая задача на интервал. По умолчанию категории: кафе, рестораны, салоны красоты, парикмахерские, автосервисы, шиномонтаж, стоматологии, ветеринарные клиники, гостиницы, фитнес-клубы, цветочные магазины, мебельные магазины, ремонт техники, строительные компании, клининг, детские центры, автошколы, ателье, пекарни, юридические услуги. Это стартовое покрытие, не исчерпывающий перечень всех ниш. Для своего списка используйте `--categories 'ниша1,ниша2'`.

Один браузерный запрос читает до 20 доступных в выдаче карточек, последовательно. Полный сбор всех бизнесов города, прокрутка до конца выдачи и разделение города на географические области пока не реализованы. CAPTCHA останавливает фоновую кампанию; обход CAPTCHA, смена аккаунтов и ротация прокси не выполняются.

Дневной лимит считается по попыткам и суткам UTC, включая неудачные попытки. Контакты без подключённого аккаунта остаются `pending` с пояснением, без расхода дневного лимита. `sent` — отправка подтверждена каналом; `uncertain` — результат нельзя установить, повтор автоматически не выполняется. Очередь видна через `/queue`.

## Проверки

```sh
go test -race ./...
TEST_BROWSER=1 go test -race -v ./...
```

Проверяются пагинация API на подставном HTTP-сервере, статусы сайта, сохранение и обновление результатов, CSRF и HTML-экранирование, экспорт, дневной лимит, запрет повторов, восстановление после прерывания, фильтр населения, извлечение опубликованных контактов, отсутствие отправки без подключения аккаунтов и реальное выполнение JS-разбора образцов в Chromium.

Живая проверка Яндекс Карт и тестовая отправка в собственные чаты владельца аккаунтов — отдельные обязательные шаги перед рабочей кампанией. Текущие тесты не доказывают их успешность.

## Пакет Windows

В архиве Windows находится `maps-prospector.exe` и команды:

- `start.cmd` — открыть программу без отправки сообщений;
- `login-telegram.cmd` — локальный вход Telegram (сначала задайте `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` в окружении);
- `test-vk.cmd` — после входа отправить одно проверочное сообщение только в ваше собственное тестовое сообщество;
- `login-vk.cmd` — вход личного VK через обычное окно Chrome, без API-токена;
- `login-whatsapp.cmd` — локальная привязка WhatsApp через QR;
- `run-with-vk.cmd` — дополнительный API-режим: скрытый ввод пользовательского VK-токена в локальной PowerShell-консоли, проверка доступа и запуск с автоотправкой; токен не сохраняется в файл. При наличии `cities.csv` запускается кампания по городам, иначе поиск выполняется через форму.
- `check-vk.cmd` — проверить пользовательский VK-токен и разрешение сообщений без отправки;
- `refresh-cities.cmd` — загрузить кандидатов городов в `cities.csv`;
- `start-campaign.cmd` — поиск по городам и автоотправка, лимит 10 попыток в сутки.

Установите Google Chrome; программа найдёт его автоматически. Распакуйте архив в отдельную папку. Сначала выполните вход в аккаунты и загрузку городов, проверьте источники численности, затем запускайте кампанию. Эти `.cmd` не скрывают код входа в отдельный сервис: ввод обрабатывается самим Go-приложением в локальном терминале. Сборка для Windows выполнена из Linux; запуск `.exe` на реальном Windows и работа аккаунтов ещё не проверялись.

Обновление VK: добавлены проверки личного токена и разрешения `messages`, разрешение опубликованной ссылки в отрицательный ID сообщества и тесты отказов. 21 основной тест проходит, включая три дополнительных случая отказа VK. Проверка вашего токена и выполнение Windows-команд остаются непроведёнными.

Браузерный VK добавлен для личного профиля без API-приложения. Если у бизнеса опубликована ссылка VK, она выбирается первой. Только распознанные элементы активного диалога используются для проверки адресата; контакт в боковом списке не считается подтверждением открытого диалога. Браузерный адаптер требует проверки на реальном интерфейсе до рабочей отправки.
